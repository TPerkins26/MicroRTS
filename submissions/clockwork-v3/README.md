# Clockwork V3

A deterministic anti-rush MicroRTS bot. It prioritizes an early barracks, trains Light units continuously, keeps one worker harvesting, and sends extra workers toward the nearest enemy in a WorkerRush-style attack posture. Combat units defend the base against immediate threats and hold forward defense until they outnumber enemy combat troops.

The fully qualified class is `ai.abstraction.submissions.clockwork_v3.ClockworkBotV3`.
